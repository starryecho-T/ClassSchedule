# ClassSchedule 课表 📅

一款简洁美观的 Android 课表应用，帮助你一目了然地查看每周课程安排。

> 当前版本：**0.9.1（22）**。教务导入新增自定义吉大教务 / WebVPN 网址、刷新及加载错误提示，沿用现有吉大课表解析规则。[下载 v0.9.1](https://github.com/starryecho-T/ClassSchedule/releases/tag/v0.9.1) · [版本说明](docs/release-0.9.1.md)。

## 0.9 使用说明

- 在“我的 → 从教务导入”输入吉大教务或学校 WebVPN 的 HTTPS 地址，点击“打开”，在应用内登录并进入课表后识别；不需要自行下载 JSON。
- 在“我的 → 备份课表”选择保存位置，导出完整 JSON；在“恢复课表”选择文件并核对预览。
- 默认追加去重，保留已有颜色与隐藏状态。替换需再次确认，保留备份内重复记录及隐藏状态；不沿用数据库 ID。
- 仅接受本应用 version=1 协议、相同学期配置（目前 2026-09-07 开学 / 17 周 / 每天 12 节）的备份。
- 空备份不会清空现有课表；任一记录非法、未知协议、超限或读写失败会明确提示。
- 本版为手动明文备份，不包含教务登录、系统授权和小组件摆放；卸载前保存到卸载后仍可访问的位置。
- 未授权精确闹钟时降级为普通提醒，可能延后；不会因注册精确闹钟抛异常而退出应用。
- 喜欢本项目，欢迎在“我的 → GitHub 项目”访问仓库并点亮 Star ★。
- 在“我的 → 外观模式”选择跟随系统、浅色或深色，默认跟随系统；重启后保留选择。

## 🚀 快速开始

### 环境要求

- Android Studio Ladybug 或更高版本
- JDK 17
- Android SDK Platform 35

### 构建运行

```bash
git clone https://github.com/starryecho-T/ClassSchedule.git
```

1. 用 Android Studio 打开项目根目录，等待 Gradle Sync 完成；
2. 连接手机（开启开发者模式 + USB 调试）或启动模拟器；
3. 点击 Run ▶️ 安装运行。

> 💡 提示：仓库已包含 Gradle Wrapper（`gradlew` / `gradle-wrapper.jar`），首次 Sync 时
> Gradle 会自动下载对应发行版；若网络较慢，可将 `gradle/wrapper/gradle-wrapper.properties`
> 中的 `distributionUrl` 换成腾讯镜像地址。

## 🎓 吉林大学适配

- 作息时间表集中在 `app/src/main/java/com/classschedule/app/data/JluTimeTable.kt`，
  默认为「上午 4 节 + 下午 4 节 + 晚上 4 节」共 12 节，可按校区实际作息修改；
- 周视图按节次数自动排布，改作息无需改界面代码；
- 示例数据中的教学楼名称（李四光楼、唐敖庆楼、经信教学楼等）仅作演示。

## 一键导入首版（开发中）

1. 打开应用内教务导入，完成学校登录及验证码。
2. 进入“我的教学 → 我的课表”，选择当前学期并切换到列表模式。
3. 点击“一键识别课表”，识别成功后自动显示完整课程预览。
4. 核对学期、周次、节次、教室，勾选确认后导入。默认保留已有课程，重复安排会跳过。

替换全部课程需要主动勾选，并再次确认；分页列表请逐页识别、追加。导入前会重新核对页面内容，页面变化时必须重新识别。未知时间格式、缺失字段、越界周次或不完整抓取会停止整批导入，不会将猜测结果写入课表。

本轮 87 项 JVM 逻辑测试通过（原有 29 项，加上 39 项解析测试、19 项导入策略测试），并自 v0.7.2 起在完整 Gradle 工具链下全部通过、纳入发布流水线。这些测试没有验证真实 Room 事务回滚、Android 界面或学校在线页面。支持格式和验收步骤见 [导入说明](docs/import-first-pass.md)。
