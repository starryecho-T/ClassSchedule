# 教务导入：自定义网址入口

2026-10-19 开发变更，纳入 v0.9.1 / versionCode 22。

## 范围

仅为现有吉大课表导入增加入口选择，不扩展其他学校的课表解析规则。默认仍打开吉大教务；用户可以输入学校 WebVPN 或其他吉大教务入口，在应用内完成登录并进入“我的课表”，再识别、核对和导入。

## 抓取原理

WebView 显示用户已登录的页面。点击识别时，capture_schedule.js 读取已渲染的课表表格、课程卡片及可访问的同源子页面，自行序列化为 JSON 返回 Kotlin 解析器。它不是下载学校提供的 JSON 接口。解析器仍使用已有的吉大网格和列表规则，识别后先预览，确认才写入数据库。

网址输入只改变访问入口，不跳过学校登录、网络限制或跨域限制。外部浏览器的登录状态不会通过粘贴网址自动转入应用。WebVPN 中跨域子页面仍可能需要直接进入课表所在页面。

## 本次改动

- 增加网址输入、打开、刷新及返回教务首页；键盘“前往”可提交，省略协议时补 HTTPS。
- 保留网址路径、查询参数和片段，支持带路径及端口的 HTTPS 入口；不启用明文 HTTP 或本地文件访问。
- 页面跳转更新地址栏，取消旧识别结果；加载中或失败时不允许抓取。
- 增加加载状态、长时间加载提示、网络错误、HTTP 错误和证书错误提示；不忽略证书校验。
- 补充导入页系统栏与键盘避让。未修改已有课表解析器或数据库结构。

## 验证范围

本地 JVM 测试包括 URL 校验、带参数的 WebVPN 路径、默认协议、非法链接及输入限制。

新增设备回归代码覆盖自定义入口跳转、课表识别预览、刷新和 HTTP 错误。设备回归未完成通过：已观察到测试的页面生命周期及异步弹窗关闭时序问题；修正即时关闭断言为等待关闭。按用户要求停止真机测试，后续只执行本地构建、JVM 测试、Lint 和设备测试代码编译，不将设备用例记为通过。

真实吉大 WebVPN 登录流程、手机交互及页面加载仍待后续验证。按用户要求，v0.9.1 发布时仅构建安装包，不重新运行测试或真机验证。
