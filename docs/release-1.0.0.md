# ClassSchedule v1.0.0

发布日期：2026-10-24。版本号 1.0.0，versionCode 23。

## 学期切换

- 内置吉林大学《2026-2027 学年教学日历》：第一学期 2026-09-07（周一）开学，第二学期 2027-03-01（周一）开学，均 17 个教学周。
- 在「我的 → 当前学期」或点击课表页顶部的学期名称即可切换学期；周次编号、日期表头、“本周”高亮、日程概览、上课前提醒与桌面小组件全部按所选学期的开学日重新计算。
- 各学期课表数据相互独立：教务导入、手动加课、备份恢复都作用于当前学期，替换导入只清空当前学期，另一学期的课表不受影响。
- 下学期开学后从教务重新导入即可，第一学期的课表会完整保留，可随时切回查看；今后新学年只需在 `TermConfig.kt` 中追加一条学期配置。

## 更新弹窗改进

## 安装与升级

- ClassSchedule-1.0.0.apk 沿用历史签名，0.8.x / 0.9.x 可直接覆盖安装；最低 Android 8.0。
- 首次启动会自动升级本地数据库（为已有课程标注所属学期，全部归入第一学期），课表数据不变。
- 备份按学期导出与恢复：跨学期恢复会被拒绝并提示先切换学期；旧版备份在第一学期下可正常恢复。

全量 JVM 单元测试 147 项通过；真机（0.9.0 覆盖安装）验证数据库迁移、学期切换往返与课表数据完整，详见[验证记录](verification-1.0.md)。
