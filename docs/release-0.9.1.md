# ClassSchedule v0.9.1

发布日期：2026-10-19。版本号 0.9.1，versionCode 22。

## 教务导入改进

- 新增网址输入与“打开”按钮，可输入吉大教务或学校 WebVPN 的 HTTPS 地址；省略协议时自动补全 HTTPS。
- 新增“刷新”和“教务首页”入口，跳转后更新地址栏。
- 新增加载进度、长时间加载、网络错误、HTTP 错误与证书错误提示。
- 页面跳转时清除旧识别结果，加载中或失败时禁用识别，避免误用上一页的数据。
- 改善导入页的系统栏及键盘避让。

## 使用方式

“我的 → 从教务导入” → 输入网址并打开 → 在应用内登录 → 进入“我的课表”并选择学期 → “一键识别课表” → 核对并导入。

仍沿用现有吉大课表解析规则，不扩展其他学校格式。抓取的是已渲染的课表内容，由应用整理成 JSON；无需用户获取学校 JSON 接口。自定义网址不会跳过学校登录、网络访问或跨域限制。

## 安装与验证范围

ClassSchedule-0.9.1.apk 沿用历史 debug 签名，支持覆盖同签名旧版本；最低 Android 8.0。数据库结构不变。

按要求，本次发布仅构建 APK，不重新运行自动化测试或真机验证。此前开发阶段 136 项 JVM 单元测试通过；新增真机回归未完成通过，真实 WebVPN 登录流程仍待验证。
