# 一键导入首版说明

日期：2026-10-17。此文记录开发状态，不能代替正式版本发布说明。

## 已实现

- 在应用内登录真实教务页面；账号、密码及验证码由用户直接在学校页面输入。
- 从已渲染的 HTML 表格、ARIA 表格和可访问的同源子页面读取课程列表。
- 展开合并单元格，提取可见文字；不执行未知接口请求，不猜测缺失时间。
- 识别后自动打开预览；用户核对学期和课程后才保存。
- 默认追加并跳过完全相同的课程安排，保留已有课程与隐藏设置。
- 主动选择替换并二次确认后，使用 Room 事务替换全部课程。
- 提交前重新抓取并比较课程及页面地址；内容变化则要求重新识别。
- 不能完整识别时拒绝整批导入，可主动导出 HTML 快照帮助后续适配。

## 当前支持的输入

列表必须包含明确的课程名称，并提供完整时间字段。支持以下表头：

| 内容 | 表头示例 |
| --- | --- |
| 课程名 | 课程名称、课程名 |
| 教师（可为空） | 授课教师、任课教师、教师 |
| 教室（可为空） | 上课地点、教学地点、教室 |
| 星期 | 星期、星期几、上课星期 |
| 节次 | 节次、上课节次 |
| 周次 | 周次、上课周次 |
| 合并时间 | 上课时间、时间地点 |

以下为人工构造的测试格式，不是吉林大学真实页面样本：

| 课程名称 | 星期 | 节次 | 周次 | 教室 | 教师 |
| --- | --- | --- | --- | --- | --- |
| 示例课程甲 | 星期一 | 1-2节 | 1-16周(单) | 示例教室 | 示例教师 |
| 示例课程乙 | 周四 | 5-6 | 1-3、5、8-9周 | 示例教室 | 示例教师 |

合并时间示例：`1-16周 星期一 第1-2节 教室:示例教室`。合并字段只接受一组完整时间；多时段必须拆成独立行。不同星期或节次的同名课程会作为不同安排保留。

课程范围与当前应用一致：第 1—17 周、第 1—12 节、星期一至日。单双周必须同时给出明确范围；不会将空周次默认成全学期，也不会截断超出范围的周次。

## 当前限制

1. 尚无真实登录后的吉林大学页面样本，未完成学校页面适配验收。入口修正为 `https://iedu.jlu.edu.cn`。若实际课表不是受支持的列表结构，需要进一步适配。
2. 当前采集已加载的数据，不自动翻页或滚动加载。分页请逐页追加；不可把一页误当完整课表执行替换。
3. 跨域子页面无法直接读取；需在可直接访问的课表页面重新识别。虚拟列表、异常行列数、尺寸超限或任一识别错误都会阻止整批导入。
4. 当前学期仍由应用现有配置决定，导入页不会自动修改开学日期。必须人工核对所选学期。
5. 去重键由课程名、教师、教室、星期、起止节次和周次集合组成。文本或周次有变化时视为不同安排，不会自动合并或覆盖原安排。
6. 页面快照即使移除脚本和表单值，仍可能含姓名、学号及页面文本。只在用户选择保存位置并确认后导出，分享前请检查并移除个人信息。无需提供密码或验证码。

- 直接使用本地 Kotlin 编译器编译纯逻辑并通过 JUnit 运行 **87 项测试**。
- 其中原有 29 项，新增表格解析 39 项，导入校验及去重策略 19 项。
- 网页采集脚本通过 Node 语法检查和 **16 项最小 DOM 模型测试**；这不等同于真实浏览器验收。另有 22 项真实浏览器测试已编写，当前环境 Edge 启动受限，未完成。
- DAO 测试使用内存假实现，只验证校验、去重、隐藏状态保留及调用顺序；没有验证真实 Room 事务回滚或并发隔离。

- 未进行真实学校页面、手机 WebView 或界面的设备验收。

## 本机验收步骤

采集回归脚本位于 `tools/test-import-capture.cjs`。`node tools/test-import-capture.cjs --mock` 运行最小模型测试；去掉 `--mock` 可使用本机 Edge/Chrome 运行真实 DOM 测试，也可用环境变量 `CAPTURE_TEST_BROWSER` 指定浏览器可执行文件。

1. 同步后运行 `:app:assembleDebug :app:testDebugUnitTest`，确认资源编译、Kotlin 编译、Room KSP 和单元测试全部通过。
2. 安装生成的调试 APK，进入教务导入，登录后选择当前学期列表。
3. 识别并逐项比较预览与原课表，尤其核对单双周、离散周、周日、同名课程的多时段和合并单元格。
4. 默认追加一次，回到主页确认课程；相同页面再次导入应显示没有新增，已有隐藏设置应保留。
5. 在预览后切换学期或页面，应要求重新识别；取消预览或旋转屏幕后不能写入旧结果。
6. 在可丢弃的测试数据上验证替换确认和数据库失败回滚，不能只靠内存 DAO 单测认定事务有效。
7. 未识别时导出并脱敏页面快照，据真实结构补充测试夹具和专门适配后再发布稳定版。
