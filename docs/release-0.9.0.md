# ClassSchedule v0.9.0

## 新增与改进

- 底部“课表 / 日程 / 我的”三 Tab，切换与页面重建保留浏览状态。
- JSON 课表备份与恢复：追加去重、替换前二次确认、完整校验与事务回滚，保留颜色及隐藏状态。
- “我的 → 外观模式”支持跟随系统、浅色、深色，重启保留选择；课表、日程、弹窗与今日课程小组件配色同步适配。
- 新增 GitHub 项目入口，欢迎 Star、反馈和参与改进。
- 简化“我的”页面，移除末尾两段常驻说明。

## 修复

修复未获得精确闹钟授权时，启动或重算提醒抛出 SecurityException 导致“由于自身原因造成异常”的问题。无法精确调度时使用普通提醒，并处理权限撤销竞态。

## 安装与说明

下载 ClassSchedule-0.9.0.apk 可覆盖已有同签名版本；建议先备份课表。版本号 0.9.0，versionCode 21，最低 Android 8.0。本包沿用历史 debug 签名以兼容升级。

备份是明文 JSON，包含课程、教师和教室信息，请妥善保管；不包含登录态与系统权限。仅支持相同学期配置。未授权精确闹钟时提醒可能延后。

## 验证

131 项 JVM 单元测试、8 项 Android 16 真机测试通过；Debug / Release 构建通过，Lint 0 错误（32 警告）。同签名升级与课程数据保留已核对。详细范围和未覆盖项见 docs/verification-0.9.md。
